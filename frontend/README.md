# VTOP Hackathon Round 2 Frontend

## Included modules
- Professional VTOP landing page
- Role-based demo login
- Student dashboard
- Persistent VTOP sidebar
- Shuttle tracking frontend
- Lost & Found frontend
- Attendance frontend with subject-wise calculations

## Attendance flow
Dashboard -> Attendance -> Subject -> Attendance Details / Frontend Demo Controls

## Attendance formula
Attendance % = (Attended Classes / Total Classes) * 100

## Demo login
Student: student / student123
Employee: employee / employee123
Parent: parent / parent123
Alumni: alumni / alumni123

## Run

npm install
